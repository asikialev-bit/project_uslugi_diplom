# Сервис интеллектуального сопоставления услуг

Прототип сервиса для поддержки ценовых решений малого бизнеса: помогает сравнивать предложения конкурентов на услуги по составу работ, объёму, условиям, ограничениям и обязательным доплатам, а не только по названию и минимальной цене.

## Текущее состояние

Реализован рабочий прототип сервиса на Python + FastAPI + Pydantic + SQLite и веб-интерфейс в `frontend/`:
- доменные модели и гибкая нормализация единиц (`app/models/`);
- независимая проверка полноты данных и правил сопоставимости (`app/rules/`);
- калькулятор стоимости с пересчётом единиц и активацией условных доплат (`app/calculator/`);
- изолированное хранилище SQLite (`app/storage/`), LLM-экстрактор (`app/llm/`) и REST API (`app/main.py`);
- две веб-страницы с автоподстройкой светлой и тёмной темы (`/` — обзор, `/workspace` — рабочий стол сравнения).

## Установка и запуск

1. Создайте и активируйте виртуальное окружение (если ещё не создано):
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Скопируйте файл переменных окружения:
   ```bash
   cp .env.example .env
   ```

4. Запустите сервер для разработки:
   ```bash
   uvicorn app.main:app --reload
   ```
   После запуска:
   - Обзорная страница сервиса: `http://127.0.0.1:8000/`
   - Рабочий инструмент сравнения: `http://127.0.0.1:8000/workspace`
   - Документация API (Swagger): `http://127.0.0.1:8000/docs`
   - Проверка здоровья: `http://127.0.0.1:8000/health`
